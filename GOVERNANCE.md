# GOVERNANCE

## Roles

- **Maintainer**: Full repository access, reviews and merges changes, manages releases.
- **Contributor**: Submits issues and pull requests.
- **Security Contact**: Handles vulnerability reports privately.

Current maintainer: @magicblueentity

## Process

- Changes go through pull requests.
- Security-sensitive changes require maintainer review.
- Releases are created from `main` via version tags.
